# Confirm before changing any section or any user

**Required before any new change.** Follow `.cursor/skills/confirm-before-change/SKILL.md`.

This applies to the **whole website** and **every user role**, not only Political Intelligence or SM A.

- Check previous requirements in this conversation and recent commits.
- Ask which users and which screens before adding, removing, hiding, or moving anything.
- Do not implement extra features the user did not confirm.
- After a change, verify other roles and other sections still match their last confirmed requirements.

Follow the canonical copy at `.cursor/skills/complete-commit-deploy/SKILL.md`.

After every code change: add/update skills if the workflow changed, push to git, deploy GitHub Pages (`npm run build` then `npm run deploy` in `frontend/`), and deploy Render by updating `origin/main`.

On every UI change, follow `.cursor/skills/cross-device-ui-parity/SKILL.md`: laptop, desktop, tablet, iPad, and mobile must keep the same alignment and the same information.

Before any new product/UI/role change, follow `.cursor/skills/confirm-before-change/SKILL.md`. That applies to every section and every user, not only SM A.
